# 処理詳細設計書

## 機能情報

| 項目 | 内容 |
|------|------|
| 機能ID | F-008 |
| 機能名 | 注文確定処理 |
| HTTPメソッド / URL | POST /api/orders |
| 入力 | ログインユーザーID（セッションから取得） |
| 出力 | HTTP 201 Created / `{"order_id": 123}` |
| 関連クラス | OrderController、OrderService、CartMapper、OrderMapper、ProductMapper |
| 使用テーブル | cart_items、orders、order_items、products |
| トランザクション範囲 | 処理No.5～8 |

---

## 処理フロー

| No. | 処理内容 | 使用テーブル | 担当 | 条件分岐・例外 |
|----|-----------|-------------|------|---------------|
| 1 | ログインユーザーIDを取得する | - | OrderController | 未認証の場合：401 |
| 2 | cart_itemsからカート情報を取得する | cart_items | CartMapper | カートが空の場合：400「カートが空です」 |
| 3 | 各商品の在庫を確認する | products | ProductMapper | 在庫不足の場合：400「○○の在庫が不足しています」 |
| 4 | 合計金額を計算する | products | OrderService | - |
| 5 | **トランザクション開始** | - | OrderService | - |
| 6 | ordersへ注文情報を登録する | orders | OrderMapper | DBエラー：ロールバック |
| 7 | order_itemsへ注文明細を登録する | order_items | OrderMapper | DBエラー：ロールバック |
| 8 | productsの在庫を更新する | products | ProductMapper | DBエラー：ロールバック |
| 9 | cart_itemsを削除する | cart_items | CartMapper | DBエラー：ロールバック |
| 10 | **トランザクション終了（コミット）** | - | OrderService | - |
| 11 | 注文IDを返却する | orders | OrderController | HTTP201 |

---

## 処理フロー（擬似コード）

```text
開始

ログインユーザーID取得

cart_items取得

IF カートが空 THEN
    400エラー「カートが空です」
END IF

合計金額 = 0

FOR カート内の商品

    products取得

    IF 在庫 < 注文数量 THEN
        400エラー「商品名の在庫が不足しています」
    END IF

    合計金額 += 商品価格 × 注文数量

END FOR

トランザクション開始

ordersへINSERT

FOR カート内の商品

    order_itemsへINSERT

    products.stock -= 注文数量

END FOR

cart_items削除

コミット

注文ID返却

終了

例外発生

ロールバック

500エラー返却
```

---

## トランザクション

| 開始 | 終了 | 理由 |
|------|------|------|
| orders登録 | cart_items削除 | 注文登録・明細登録・在庫更新・カート削除を1つの処理として保証するため |

## 例外処理

| 例外 | HTTP | レスポンス |
|------|------|------------|
| EmptyCartException | 400 | `{"message":"カートが空です"}` |
| InsufficientStockException | 400 | `{"message":"○○の在庫が不足しています"}` |
| DataAccessException | 500 | `{"message":"サーバーエラーが発生しました"}` |
| UnauthorizedException | 401 | `{"message":"認証が必要です"}` |
