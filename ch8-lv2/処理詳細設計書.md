# Ch.8 課題2：処理詳細設計書の作成

## タスク管理システムの処理詳細設計書


| メソッド名                                      | 処理概要        | 引数              | 戻り値     | 処理ステップ                             | 例外・特記事項                           |              |
| ------------------------------------------ | ----------- | --------------- | ------- | ---------------------------------- | --------------------------------- | ------------ |
| MemberRepository.findById(String memberId) | メンバーIDで検索する | memberId:String | Member  | null時あり                            | ①検索開始→②比較→③一致なら返却→④最後まで検索→⑤null返却 | 存在しない場合はnull |
| TaskService.addTask(Task task)             | タスクを登録する    | task:Task       | boolean | ①容量確認→②登録→③件数更新→④true→⑤満杯ならfalse   | 配列上限で登録不可                         |              |
| TaskService.printTaskList()                | タスク一覧表示     | なし              | なし      | ①見出し表示→②タスク走査→③担当者検索→④存在確認→⑤表示→⑥終了 | 担当者が見つからない場合は表示しない                |              |
