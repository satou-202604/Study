# 請求書発行システム ログ設計書


| ログID | ログレベル | 出力タイミング | ログメッセージ例 | 出力先 | 備考 |
|--------|------------|----------------|------------------|--------|------|
| LOG-001 | INFO | `generateInvoice()` 呼び出し時（請求書生成開始） | [INFO] InvoiceService - 請求書生成開始: customerId={}, 明細件数={} | アプリケーションログ | 請求書生成処理の開始を記録する |
| LOG-002 | DEBUG | `findById()` 呼び出し直前 | [DEBUG] CustomerRepository - 顧客検索開始: customerId={} | アプリケーションログ | 検索条件（customerId）の確認 |
| LOG-003 | INFO | 顧客検索成功時 | [INFO] CustomerRepository - 顧客検索成功: customerId={}, companyName={} | アプリケーションログ | 顧客情報を正常に取得したことを記録する |
| LOG-004 | WARN | 顧客が見つからず `null` を返却した時 | [WARN] CustomerRepository - 顧客が見つかりません: customerId={} | アプリケーションログ | 呼び出し元で例外処理を行う前の警告ログ |
| LOG-005 | DEBUG | `calcSubtotal()` 実行後（明細ごと） | [DEBUG] InvoiceService - 明細計算: description={}, quantity={}, unitPrice={}, subtotal={} | アプリケーションログ | 各明細の小計計算結果を確認する |
| LOG-006 | DEBUG | 合計・消費税計算後 | [DEBUG] InvoiceService - 合計計算: total={}, tax={}, totalWithTax={} | アプリケーションログ | 税込金額の計算結果を確認する |
| LOG-007 | INFO | 請求書生成処理が正常終了した時 | [INFO] InvoiceService - 請求書生成完了: customerId={}, 税抜合計={}円, 消費税={}円, 税込合計={}円 | アプリケーションログ | 正常終了を記録する |
| LOG-008 | ERROR | `IllegalArgumentException` など例外発生時 | [ERROR] InvoiceService - 請求書生成失敗: customerId={}, エラー={} | エラーログ | 例外メッセージとスタックトレースを出力する |
